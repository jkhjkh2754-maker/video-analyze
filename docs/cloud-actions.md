# GitHub Actions 다운로드 시험

이 워크플로는 수동 실행만 지원합니다. 코드 push·PR·일정으로 자동 실행하지 않습니다. 표준 `ubuntu-24.04` 실행기에서 무료 도구를 설치하고 실제 영상 파일을 받아 FFprobe로 확인합니다. 비공개 저장소에서는 job 전체를 건너뜁니다. 추가 저장 비용을 방지하기 위해 아티팩트 업로드와 캐시를 사용하지 않고, 이번 시험 결과는 실행 로그와 job summary에 표시합니다.

## 실행

1. 저장소 공개 전환 전에 기존 코드·문서·커밋에 비밀정보나 공개하면 안 되는 자료가 없는지 확인합니다. 이 워크플로가 저장소 공개 여부를 변경하지는 않습니다.
2. 기본 브랜치에 `.github/workflows/youtube-download-probe.yml`과 `scripts/cloud_download_probe.py`가 있어야 수동 실행 목록에 표시됩니다.
3. Actions → YouTube download probe → Run workflow에서 이용 권한이 있는 단일 영상 URL을 입력합니다.
4. 완료 후 job summary와 Download and verify actual media 단계의 JSON 출력에서 검증 결과를 확인합니다. 다운로드 실패 시 URL을 가린 로그도 같은 단계에 표시됩니다.

`download_verified`는 실제 영상 파일 존재·크기·영상 스트림·원본 대비 길이를 검증한 경우에만 기록합니다. 실패 또는 필터로 건너뛴 경우 성공으로 보고하지 않습니다. 본편이 다운로드되더라도 자막 다운로드 오류로 전체 명령이 실패하면 실패로 표시합니다.

## 범위와 비용

- 수동 실행, 동시 1개, 실행당 15분 제한, yt-dlp 하위 프로세스 11분 제한.
- 1시간 이하의 완료된 영상, 720p 이하 형식, 형식별 2GB 제한. 용량 정보가 없는 형식은 미리 크기를 확정할 수 없습니다.
- 계정·쿠키·외부 프록시·PO token·유료 API는 사용하지 않습니다. 접근 제한 시 실패를 기록합니다.
- 원본 영상·info.json·보고서 파일은 러너 임시 디스크에만 둡니다. Git 커밋과 아티팩트에 포함하지 않습니다. 검증 JSON과 URL을 가린 오류 로그는 실행 로그에 출력합니다.
- 공개 저장소에서는 실행 로그도 공개됩니다. 공개하면 안 되는 영상 URL을 입력하지 마세요.
- 공개 저장소의 표준 러너 무료 컴퓨팅 설명: https://docs.github.com/en/actions/concepts/billing-and-usage
- 실제 다운로드가 성공한 후에 전사·프레임·분석 ZIP 전체 처리 연결을 진행합니다. 현재 단계는 다운로드 시험입니다.
