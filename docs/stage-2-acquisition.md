# 2단계 영상 확보 보고서

> 이 문서의 아래 내용은 복원한 과거 기록입니다. 현재 환경은 unrestricted/enforced, 설정·적용 버전 모두 1이며, 새 연결의 프록시 CONNECT 403이 확인됐습니다. 과거의 제한 모드·도메인 추가 안내는 현재 진단에 적용하지 않습니다. [현재 네트워크 검증](current-network-verification.md)을 우선 참고하세요.

점검일: 2026-11-07 UTC. 사용자가 YouTube 접근 및 2단계 진행을 승인함.

## 구현

`analyzer.py`에 단일 HTTPS YouTube URL 검증, yt-dlp 호출, 수동·자동 자막 확보, 메타데이터 및 처리 결과 JSON 저장을 구현했다. 외부 라이브러리는 1단계의 yt-dlp만 사용한다. 각 실행은 별도 downloads 하위 폴더를 사용한다.

명령줄 입력은 셸로 실행하지 않는다. yt-dlp 외부 설정을 무시하며 로그인·쿠키·지역 우회 기능을 제공하지 않는다. 접근 제한과 네트워크 오류는 실패로 기록한다. ffprobe로 실제 영상 스트림을 확인해야 확보 성공으로 판정한다. 원본 미디어의 FFmpeg 병합은 수행할 수 있으나 프레임 추출은 구현하지 않았다.

자막이 없는 경우 무료 로컬 음성 인식 구현은 남아 있다. 해당 상태는 결과에 명시하며 전사 또는 분석 완료로 보고하지 않는다.

## 검증 결과

- 로컬 unittest 8개 통과: URL 검증, 수동 자막 우선, 자동 자막 선택, 자막 없는 경우 전사 대기, 파일 미확보 실패, 제한 영상 중단, 네트워크 실패 기록, 라이브 중단.
- 다운로드 호출은 테스트 대역으로 검증했으며 실제 FFmpeg 합성 파일을 ffprobe로 검사했다. 테스트는 YouTube 다운로드 성공을 입증하지 않는다.
- CLI 도움말 정상. 잘못된 URL 종료 코드 2 확인. 실제 설치 yt-dlp를 프로그램 호출 경로에서 실행해 버전 확인.
- 사용자 제공 시험 URL: https://youtu.be/Z0aXJeC4HiE (공유 추적 매개변수 제거).
- 실제 프로그램 실행: 종료 코드 1, `NETWORK_ERROR`. yt-dlp 로그에서 `Tunnel connection failed: 403 Forbidden` 확인.
- 실제 실행 결과: `downloads/20261107T124632Z-0412c881/result.json`, 진단 로그는 동일 폴더의 `processing.log`.
- 영상·자막·메타데이터 확보는 실패했다. 해당 실행에는 결과 JSON과 로그만 존재한다.

## 네트워크 원인과 필요한 조치

사용자 승인 후 환경 상태와 새 연결을 확인했으나 제한 네트워크 정책은 변경되지 않았다. YouTube robots.txt 접속도 프록시 CONNECT 403으로 실패했다. 현재 도구 목록에 네트워크 정책 변경 도구가 없어 설정 변경을 수행하지 못했다. 이는 사용자 승인 거절이나 자동 승인 심사 거절이 아니라 환경의 목적지 차단이다.

실행 환경 설정에서 기존 허용 목록을 유지하며 `youtube.com`, `*.youtube.com`, `youtu.be`, `*.googlevideo.com`, `*.ytimg.com` 접근 허용을 검토해야 한다. 실제 요청에 따라 추가 목적지가 필요할 수 있다. 설정이 적용되면 새 연결로 재확인하고 동일 URL 시험을 다시 수행해야 한다. 영상 자체의 로그인·연령·지역 등의 제한은 해제하거나 우회하지 않는다.

## 남은 검증 및 단계 상태

실제 영상과 자막 다운로드 성공, 원격 메타데이터 필드, YouTube JavaScript 처리 호환성, 자막 없는 영상의 로컬 전사는 미검증이다. 현재 상태는 **2단계 코드 구현 및 로컬 검증 완료, 실제 자료 확보 검증 차단**이다. 유료 서비스 호출·결제·GitHub push는 수행하지 않았다. 3단계는 시작하지 않았다.

## 설정 변경 후 재확인 (2026-11-07 12:58 UTC)

사용자가 설정 적용을 알린 뒤 환경 상태와 새 HTTPS 연결을 확인했다. 현재 실행 인스턴스는 계속 spec_revision=1 / observed_spec_revision=1이며 observations_current=true, 네트워크 정책 enforced, 사용자 지정 allowed_hosts=[]로 조회됐다. 전체 허용 목록에도 YouTube 관련 도메인은 없었다. 기본 샌드박스에서는 프록시 연결 실패, 승인된 외부 실행 경로에서도 YouTube robots.txt에 CONNECT HTTP 403이 발생했다. 현재 인스턴스에는 변경이 반영된 증거가 없다. 설정이 다른 환경 또는 향후 실행용 버전에 저장되었을 가능성은 있으나 확인되지 않았다. 다운로드를 반복하지 않았으며 실제 자료 확보 상태는 여전히 미검증이다. 변경한 환경 설정을 현재 실행에 적용하거나 해당 설정으로 환경을 다시 연결한 후 재확인이 필요하다.
